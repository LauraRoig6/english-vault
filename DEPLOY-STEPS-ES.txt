ENGLISH VAULT — ACTUALIZAR EN VERCEL

1. Sube/reemplaza estos archivos en tu repositorio GitHub english-vault.
2. Vercel hará un nuevo deployment automáticamente.
3. En Vercel abre tu proyecto -> Settings -> Environment Variables.
4. Añade:
   Name: OPENAI_API_KEY
   Value: tu clave de OpenAI API
   Environment: Production (y Preview si quieres probar ramas/preview)
5. Guarda la variable.
6. Haz Redeploy del último deployment para que la función /api/autofill reciba la variable.

FUNCIONES:
- Pronunciación UK/US: no necesita API.
- Surprise me: no necesita API; usa un banco local de palabras nuevas.
- Autofill with AI: necesita OPENAI_API_KEY.

IMPORTANTE:
- Nunca pongas OPENAI_API_KEY dentro de src/ ni la subas a GitHub.
- Los datos del Vault se guardan en localStorage del navegador.
